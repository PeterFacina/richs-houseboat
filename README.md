# Rich's Houseboat

This is the **Major Restoration** friends playtest. It includes Big Rich's restoration story, the Pier Road yard, repair tools, and the Notebook. It uses the local playtest baseline at `6e3c963`.

## Play on Windows

1. Clone the `playtest/major-restoration` branch or download and extract its ZIP from GitHub.
2. Use Godot 4.7.2. Put `Godot_v4.7.2-stable_win64.exe` in `build/godot`, set `GODOT_EXE` to the executable's path, or use `godot.exe` from `PATH`.
3. Run `Play Ottawa River.cmd`. The launcher imports assets on the first run and stores its test saves in `.playtest-data`.
4. Start a fresh solo slot or crew trip. Speak with Rich using **E** and accept **Gone Fishing**. Press **B** to open the Notebook.

You can also import `godot-cove/project.godot` in Godot and press **F5** to run the project. For multiplayer, use the same playtest branch on every machine.
