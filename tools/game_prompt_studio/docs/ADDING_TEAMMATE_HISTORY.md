# Import teammate history

1. Choose the project-related UTF-8 TXT or Markdown files you want the team’s Studio users to see. Export selected conversations to text outside Studio if needed.
2. Open **Imports**, select files or choose **Preview project notes**, then inspect the previews and duplicate flags.
3. Supply the original author if known and a source label that will be recognizable later. Confirm with **Import batch**.
4. **View originals** shows the stored text. Administrators can remove a batch and its searchable entries. Existing saved prompts retain evidence snapshots and text they already used.

Each batch records its uploader, original author label, source and import time. An original file’s claims and dates remain historical evidence. Deduplication compares the normalized text across batches while storing the original decoded text and a hash. Archives, structured chat exports and automatic history discovery outside the project are pending.
