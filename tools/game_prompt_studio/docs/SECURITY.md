# Security boundaries

Studio binds to 127.0.0.1. In default mode it is intended for the trusted person using that Windows session. Private mode relies on Tailscale Serve for HTTPS, verifies the configured HTTP Host and applies origin and CSRF checks. Password mode uses scrypt password hashes, revocable eight-hour sessions, secure cookies, role restrictions and sign-in rate limits. When `tailscaleUsers` is configured, Studio matches the login header supplied by the loopback Serve proxy with the allowed logins and roles. Serve removes client-supplied identity headers. The Windows host and its local processes are trusted. Keep this route private and use Serve as the sole proxy to Studio.

The app never executes prompts, game scripts, shell fragments or imported content. The Ollama adapter permits only a fixed loopback destination and tagged local models. Studio requests use no cloud inference services. Launch scripts set Ollama’s no-cloud environment option when starting Ollama. Keep any separately managed Ollama server local and disable its cloud functions.

Prompt generation accepts structured model output. The renderer adds actual source references, and an export check looks for unknown file paths, unknown citations, external links, suspicious data disclosure or command directives, and invisible control characters. Downloads and clipboard actions pass through the same checks. This is a bounded content check, so review scope and evidence before supplying the output to a coding agent.

Imports are selected bounded text files. Browser input is rendered as text. Screenshot uploads are decoded and resized in the browser, validated for PNG layout, dimensions, CRC and decompressed pixel size on the host, stripped of ancillary metadata, and served from authenticated record routes in private mode. Model requests receive optional human descriptions of screenshots. Project and personal data can persist in local exports, database backups, or evidence snapshots after removing an import or image. Treat all of these as team documents.
